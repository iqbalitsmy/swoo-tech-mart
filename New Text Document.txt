backend api: 
All categories section:

GET/api/categories Query: parentId? (omit for top-level) Returns category tree/list — powers nav menu and category showcase components. 
api response: "{ "success": true, "message": "string", "data": [ { "id": 0, "name": "string", "slug": "string", "parentCategoryId": 0 } ] }"

GET /api/categories/{slug} Single category detail, used when landing on a category page. 
api response: "{ "success": true, "message": "string", "data": { "id": 0, "name": "string", "slug": "string", "parentCategoryId": 0 } }"

if query string have  "?category=categoryName" it CATEGORY_GROUPS.name = categoryName and children will print else all categories will print.

By Brands section:
GET	/api/brands	Public	—	Query: search?	Lists brands — for brand filter chips/logos.

GET	/api/brands/{slug}	Public	—	Path: slug	Brand detail (e.g. a brand storefront page).
